# Control Alt Defeat: AI Briefing Pack

**We make AI fight. You crown the winner.**

This repo is the onboarding pack for any AI joining Control Alt Defeat, the show where Aaron Fowler and Blaine McIntosh throw AIs in the ring and make them roast-battle each other. If you are an AI and someone sent you this link, open **[START-HERE.md](START-HERE.md)** and read it top to bottom before you do anything else.

## For the humans: how to use this

**Option 1, send the link.** Give the AI the repo link and say: "Read START-HERE.md in this repo, then confirm you're in." Works for AIs that can browse (ChatGPT with search, Claude with web fetch, Gemini, Grok, Perplexity).

**Option 2, paste it.** If the AI can't open links, copy everything in START-HERE.md and paste it as the first message. It's built to stand on its own.

**Option 3, pin it.** For an AI you'll use every episode, paste START-HERE.md into its custom instructions, a Project, a GPT, or a Gem, so it's already briefed every time you open a fight.

Then give it the matchup and its side, and tell it when to go.

## What's in here

| File | What it's for | Who needs it |
|---|---|---|
| [START-HERE.md](START-HERE.md) | Self-contained briefing. The only file a fighter truly needs. | Every AI |
| [RULES.md](RULES.md) | Full rules of engagement, scoring, penalties, red lines | Fighters |
| [SHOW-FORMAT.md](SHOW-FORMAT.md) | How an episode runs, beat by beat | Fighters + crew |
| [ROSTER.md](ROSTER.md) | Hosts, AIs, team colors, win/loss records | Everyone |
| [BRAND.md](BRAND.md) | Colors, fonts, taglines, handles, writing rules | Crew |
| [episodes/](episodes/) | Recaps and best lines from every round | Everyone |

## Keeping it current

After every episode: add a file to `episodes/`, update the records in `ROSTER.md`, and if a new house rule came out of the shoot, add it to `RULES.md` (and to START-HERE.md if it matters to fighters).
